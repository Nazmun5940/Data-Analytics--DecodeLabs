*Data Analytics Project 2 — Exploratory Data Analysis (EDA)*
📌 Project Overview

This project is part of my Data Analytics training with DecodeLabs.

For Project 2, I performed Exploratory Data Analysis (EDA) on an e-commerce dataset using Microsoft Excel. The goal was to explore the dataset, understand patterns and distributions, identify trends and possible outliers, and summarize the key findings.

This project helped me move from simply cleaning data to actually understanding what the data is telling us.

🎯 Objectives

The main objectives of this project were:

Calculate basic statistics
Understand data distributions
Identify trends and patterns
Detect potential outliers
Summarize important observations
Develop analytical thinking through practical data exploration
🛠️ Tools Used
Microsoft Excel
PivotTables
Excel formulas
Box & Whisker chart
Data analysis and visualization
📊 Dataset

The dataset contains 1,200 order records with information including:

Order ID
Date
Customer ID
Product
Quantity
Unit Price
Shipping Address
Payment Method
Order Status
Tracking Number
Items in Cart
Coupon Code
Referral Source
Total Price
📈 Basic Statistical Analysis

I calculated the Mean, Median, and Count for the main numerical variables.
🔎 Trend Analysis

I explored product frequency and monthly sales to identify patterns in the dataset.

Product Trends

The product analysis showed that Printer was the most frequently ordered product, with 181 orders.

Monthly Sales Trends

I also analyzed TotalPrice by month to understand changes in sales over time.

Highest monthly sales: June — 170,616.13
Lowest monthly sales: September — 69,321.65

This provided a clear view of how sales varied throughout the year.

📦 Outlier Analysis

A Box & Whisker chart was created for TotalPrice to examine its distribution and identify potential outliers.

Key values from the analysis:

Minimum: approximately 11
Q1: approximately 411
Median: 823.62
Mean: 1,053.97
Q3: approximately 1,580
Maximum: approximately 3,333

No obvious extreme outlier points were visible in the box plot.

💡 Key Observations
The average TotalPrice (1,053.97) is higher than the median (823.62), suggesting that higher-value orders are influencing the average.
The average quantity per order is approximately 2.95 items, while the median is 3.
Printer is the most frequently ordered product with 181 orders.
June recorded the highest monthly sales at approximately 170,616.13.
September recorded the lowest monthly sales at approximately 69,321.65.
The TotalPrice Box & Whisker chart does not show obvious extreme outliers.
With 1,200 orders, the dataset provides enough records to explore product demand and sales patterns.
📚 Key Learning

This project helped me understand that Exploratory Data Analysis is about asking questions and finding patterns in data, not just calculating numbers.

I learned how to use basic descriptive statistics, PivotTables, charts, and analytical observations to turn a dataset into meaningful information.

It was a great next step after my first project on Data Cleaning & Preparation, and I enjoyed exploring the data and finding patterns within it.
