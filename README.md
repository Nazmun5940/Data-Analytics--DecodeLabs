Data Analytics Project 1 — Data Cleaning & Preparation
📌 Project Overview

This project is part of my Data Analytics training with DecodeLabs.

For Project 1, I worked with a raw dataset and focused on data cleaning and preparation using Microsoft Excel. The main goal was to transform the raw data into a clean, structured, and reliable dataset that can be used for further analysis.

I particularly enjoyed working with the raw dataset and going through the cleaning process step by step. It helped me understand how important data quality is before moving on to visualization or analysis.

🎯 Objectives

The main objectives of this project were:

Identify missing or null values
Remove duplicate records
Check and correct data formats
Validate IDs and other fields
Ensure dates are correctly formatted
Check numerical data for consistency
Prepare the dataset for further analysis

These requirements are based on the DecodeLabs Project 1 guidelines.

🧹 Data Cleaning Process

I worked through the raw dataset and performed several validation and cleaning steps:

1. Missing Values

Checked the dataset for blank or null values and ensured the required fields were properly populated.

2. Duplicate Records

Checked the dataset for duplicate Order IDs and verified that there were no duplicate IDs.

3. Date Formatting

Checked the Date column and ensured that the dates were stored consistently in the required format.

4. Data Format Validation

Reviewed different fields including:

Order ID
Customer ID
Product
Quantity
Unit Price
Order Status
Tracking Number
Coupon Code
Referral Source
Total Price
5. Data Validation

I also checked the numerical values and verified that the calculated Total Price was consistent with the Quantity and Unit Price.
